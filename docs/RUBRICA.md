# Seguimiento de calidad

Lista interna de objetivos tecnicos.

- [ ] Abstracciones utiles y responsabilidades claras.
- [ ] Encapsulamiento e invariantes.
- [ ] Polimorfismo de las cinco variantes.
- [ ] Composicion y bajo acoplamiento.
- [ ] Principios SOLID.
- [ ] Motor de reglas y apuestas.
- [ ] Conservacion de fichas y botes secundarios.
- [ ] Interfaz movil funcional.
- [ ] Adaptacion a ambas orientaciones.
- [ ] Pruebas automatizadas del dominio.
- [ ] Documentacion y capacidad de explicar el codigo.

La evaluacion formal se consulta en la documentacion
academica correspondiente, mantenida fuera del repositorio.
